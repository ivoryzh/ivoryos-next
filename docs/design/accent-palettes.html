IvoryOS · accent colour

Pick an accent for buttons, selection and focus

Steel is what IvoryOS ships today. Each option is shown wherever the accent means "primary" or "selected". The hues that already mean something stay as they are (purple batch, green Run and online, amber warnings, red errors, the step kinds), so every preview shows the accent next to them.

Where the accent shows up

      
    
        
  • Primary buttons: Save, Queue run, Start optimization, Approve.
    • 
        
  • Selected state: the current page in the nav, the run-mode tab, a selected row.
    • 
        
  • Focus and checked: focused fields, checkboxes, switches, the open step.
    • 
        
  • Progress: the live-run strip along the top of the run card.
    • 
        
  • Cloud canvas: node handles and the selected node. A node at rest is neutral grey; "Palette tint" previews the alternative.
    • 
        
  • Not the accent: tooltips (ink), headings and labels (grey), the Run button (green) and batch controls (purple).
